# Responsible Data Use

- Use transaction data only when you have appropriate rights and authorization.
- Remove or avoid customer identifiers; this project requires only transaction and product identifiers.
- Do not infer sensitive personal traits from purchase baskets.
- Association rules can reflect promotions, availability, seasonality, and sampling bias.
- Validate recommendation quality with suitable offline metrics and controlled experiments.
- Do not present lift as proof that recommending a product will cause incremental sales.
